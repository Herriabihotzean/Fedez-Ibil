# Fedez Ibil

Dépôt statique prêt pour GitHub Pages.

## Mise en ligne
1. Créer un dépôt GitHub, par exemple `fedez-ibil`.
2. Envoyer tout le contenu de ce dossier à la racine du dépôt.
3. GitHub → Settings → Pages.
4. Source : `Deploy from a branch`.
5. Branche : `main`, dossier : `/ (root)`.
6. Enregistrer.
